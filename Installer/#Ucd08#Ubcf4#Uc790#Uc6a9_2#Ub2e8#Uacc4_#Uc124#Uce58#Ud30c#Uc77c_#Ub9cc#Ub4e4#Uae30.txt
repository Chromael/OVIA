OVIA 1차 테스트 설치파일 제작 - 2단계
========================================

중요
- 이번 설치는 OVIA Desktop만 대상으로 합니다.
- AutoCAD 플러그인은 아직 자동 설치하지 않습니다.
- 이번 테스트에서는 MD파일을 수정하지 않습니다.
- 반드시 Visual Studio에서 Release | x64 빌드가 성공한 뒤 진행합니다.

1. 파일 배치
------------
이 폴더 안의 OVIA_Test_Setup.iss 파일을 OVIA 소스 최상위 폴더의 Installer 폴더에 넣습니다.

권장 구조:
OVIA\
  OVIA.slnx
  OVIA.Desktop\
  OVIA.AutoCAD.2027\
  OVIA.PreflightCheck\
  Installer\
    OVIA_Test_Setup.iss

스크립트는 Installer 폴더의 한 단계 위를 소스 최상위 폴더로 인식합니다.

2. Release 빌드 확인
--------------------
다음 파일이 반드시 있어야 합니다.

OVIA.Desktop\bin\x64\Release\OVIA.Desktop.exe
OVIA.Desktop\bin\x64\Release\OVIA.Desktop.exe.config
OVIA.Desktop\bin\x64\Release\Microsoft.Web.WebView2.Core.dll
OVIA.Desktop\bin\x64\Release\Microsoft.Web.WebView2.WinForms.dll
OVIA.Desktop\bin\x64\Release\WebView2Loader.dll

없다면 Visual Studio 상단을 Release / x64로 바꾸고 OVIA.Desktop을 다시 빌드합니다.

3. Inno Setup 설치
------------------
Inno Setup 공식 설치 프로그램을 설치합니다.
설치 후 시작 메뉴에서 Inno Setup Compiler를 실행합니다.

4. 스크립트 열기
----------------
Inno Setup Compiler에서
File > Open을 누른 뒤 Installer\OVIA_Test_Setup.iss를 엽니다.

5. 컴파일
---------
상단 메뉴 Build > Compile을 누르거나 키보드 Ctrl+F9를 누릅니다.

성공하면 다음 위치에 설치파일이 만들어집니다.

Installer\Output\OVIA_Test_Setup_20260710.exe

6. 첫 설치 테스트
-----------------
생성된 설치파일을 마우스 오른쪽 버튼으로 눌러 관리자 권한으로 실행합니다.

기본 설치 경로:
C:\Program Files\OVIA

설치 화면에서 바탕 화면 바로가기는 선택 사항입니다.
설치 완료 화면에서 OVIA 실행을 체크한 상태로 마칩니다.

7. 설치 후 확인 항목
--------------------
[ ] C:\Program Files\OVIA\OVIA.Desktop.exe 존재
[ ] 실행파일에 OVIA 아이콘 표시
[ ] 시작 메뉴에 OVIA 바로가기 생성
[ ] 선택했다면 바탕 화면 바로가기 생성
[ ] 로그인 화면 정상 표시
[ ] ERP/WebView 화면 정상 표시
[ ] 로딩 애니메이션 정상 표시
[ ] BarList 형상 이미지 정상 표시
[ ] Data\Shapes\source_jpg에 이미지 2,115개 존재
[ ] 프로그램 제거 목록에 OVIA 표시
[ ] 제거 후 C:\Program Files\OVIA 폴더 제거

8. 의도적으로 제외한 파일
-------------------------
- OVIA.Desktop.pdb
- OVIA.Desktop.exe.WebView2 캐시 폴더
- ovia_login_save.txt
- NanumSquareNeo 폰트
- SUIT 폰트
- .git, .vs, obj 등 개발 파일

9. 이번 테스트에서 발생할 수 있는 핵심 문제
-------------------------------------------
아이디 저장 기능이 Application.StartupPath에 파일을 쓰는 구조라면 Program Files 권한 문제로 저장이 실패할 수 있습니다.
이 문제는 설치 성공 여부와 별도로 반드시 테스트합니다.

10. 컴파일 오류 시 가장 먼저 확인할 것
----------------------------------------
오류: Source file does not exist
원인: Release 빌드 파일이 없거나 Installer 폴더 위치가 잘못됨
해결: 위 권장 폴더 구조와 Release 출력 파일을 다시 확인

오류: Korean.isl을 찾을 수 없음
원인: 일부 Inno Setup 설치본에서 한국어 언어 파일이 빠짐
해결: OVIA_Test_Setup.iss의 [Languages] 아래 두 줄을 임시로 삭제하면 영문 설치 화면으로 컴파일 가능
