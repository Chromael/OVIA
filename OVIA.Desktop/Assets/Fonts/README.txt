OVIA Fonts
==========

OVIA의 포인트 UI 폰트는 Pretendard를 사용합니다.
단, 입력값/데이터/Grid/상태바/경로 표시 영역은 Windows 기본 UI 폰트(Malgun Gothic → Segoe UI → Arial)를 사용합니다.

Pretendard 적용 영역:
- 로그인 화면의 브랜드/제목/버튼
- 상단 메뉴명
- 대시보드 카드 타이틀
- 대시보드의 큰 숫자/주요 값
- 버튼 텍스트

Windows 기본 UI 폰트 적용 영역:
- TextBox / ComboBox / CheckBox 등 입력 영역
- DataGridView 데이터와 헤더
- 공사관리 / 공사별 BarList / BarList 데이터 값
- 로그인 후 상단 경로 표시
- 하단 상태 메시지 영역

권장 파일:
- Pretendard-Regular.otf
- Pretendard-Medium.otf
- Pretendard-SemiBold.otf

선택 파일:
- Pretendard-Bold.otf
- Pretendard-Light.otf

주의:
- Pretendard 파일이 없거나 로드 실패하면 포인트 UI도 Windows 기본 UI 폰트로 fallback 됩니다.
- 폰트 원본 파일은 공식 배포처에서 받은 파일을 사용하고, LICENSE.txt를 함께 유지하세요.
